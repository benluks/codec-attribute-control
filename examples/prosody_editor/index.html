Drag the blue contour to create an edit node; drag an existing handle to adjust it. Interior edits are bell-shaped; near voiced edges they automatically become shelves. Select a handle to adjust its width and shape, bypass it, or delete it (double-click or Delete). Shift-drag for fine adjustment. Pinch to zoom; two-finger scroll to pan. Each edit stays within its voiced segment.

Load an utterance to begin. This standalone HTML supports F0 analysis and target editing. A model backend must be connected for synthesis.

In standalone mode, audio stays in your browser. With a synthesis backend selected, audio and the edited F0 contour are sent to the server hosting this page. Pitch extraction uses a lightweight browser autocorrelation estimator (80 Hz frame rate); for research-grade comparison, use the same validated F0 extractor on original and converted speech in the backend.
